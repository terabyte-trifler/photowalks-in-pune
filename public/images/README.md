# These are placeholders, not photographs

Every JPEG in these folders was generated by `scripts/generate-placeholders.py`
and is stamped "PLACEHOLDER — REPLACE WITH A REAL PHOTOGRAPH" in the corner, so
nothing accidentally ships looking like community work.

To replace: keep the filename and drop your export in, or repoint the path in
`data/events.ts`, `data/photos.ts` or `data/community.ts`.

Export at ~2400px on the long edge; next/image handles AVIF/WebP conversion and
responsive sizes. Keep `hero/pune-hero.jpg` under ~250 kB — it is the only
image loaded with priority.

| Folder | Used by |
|---|---|
| `hero/` | the hero photograph and the Open Graph image |
| `walks/` | featured walk + the upcoming walks index |
| `gallery/` | the archive grid and lightbox |
| `stories/` | the featured photo story |
| `instagram/` | the Instagram grid, until the Graph API is connected |
| `logo/` | put the existing circular logo here and set `site.logo` |

Delete this file and the placeholders once real Pune photographs are in.
